# Hackathon project rules
- Always read `.hackathon/state.json` first to know the current phase.
- Score and justify every decision against `.hackathon/rubric.json` and `.hackathon/config.json`.
- `OVERVIEW.md` is the single source of truth; if it conflicts with chat, OVERVIEW wins.
- Log every change to the chosen idea in `.hackathon/changelog.md`.
- Commit at the end of every phase with message `v<N>: <summary>`.
- Never fabricate competitor links or data.
- During the build phase: edit only the files your HANDOFF file says you own.
  Never edit `.hackathon/design/contracts.md`; file a change request in your HANDOFF instead.
